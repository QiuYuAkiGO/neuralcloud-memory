## 代定并提交人工审计的决策

1. **默认用 CELLS + QUICK。** 默认启用同会话事件关联、受众预过滤、版本化两跳、有效期限和按原话日期解释。向量试验选用无外部依赖的稀疏 TF-IDF 与 RRF。稀疏融合没有新增命中，精排丢失两个命中，两个开关均保留为显式选项。稠密嵌入与 0.8B Router 主动 Push 留待独立评测，当前会话通过 Pull 取证。
2. **把语料规模和延迟口径固定在报告内。** 采用隔离的合成中文对话、同候选与上下文预算、单机单并发。P1 和 P3 的首字延迟共用确定性模型边界，真实提供方用单独的正式会话验收。此结果用于这台机器和这组难例。更大语料、不同硬件、9B 模型和网络并发需要单独测量。
3. **Master 的热目录设为显式配置，验收值为 96 token。** 通用客户端默认 0。有匹配的实模分词器才投放热目录。普通目录不会证明待办。初测时 Master 曾把目录项读成承诺，又在一份包含“已到期”的回答里继续推断旧负责人。最终实现标清未决事项、明确传达截止时间，自动刷新只传达到期事实。验收同时检查模型正文、实际输入和账本状态，拒收截断回答。
4. **后台按水位每 30 秒最多整理 16 条。** 这个选择把单页成本控制在已测规模内。空闲页也清理过期指针，积压时继续提供原文查证。卡片使用可追溯摘录，Master 仅在操作者显式给出旧印象与新证据版本时写入修订。
5. **推送到同名评审分支。** 两个仓库均使用 `codex/memory-v2-stages-3-4`，保留人工评审和合并步骤。未接入真实 QQ 群或个人日程。Gemini 收到的均为本轮合成会议材料。一次使用默认 1,024 输出 token 的调用返回 MAX_TOKENS，Harness 如约拒绝交付。最终回放为独立运行配置设 4,096，保留 STOP 和真实回执要求。
